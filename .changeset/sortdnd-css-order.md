Порядок задаётся только CSS `order` — DOM за жест не меняется вовсе

Элементы рендерятся в неизменном порядке (по id), а показывает их браузер по
`order`; раньше `<For>` шёл по порядку показа и при каждой перестановке двигал
узлы. Замеры мест снимаются на монтировании и на `ResizeObserver`, а не на
каждом старте жеста. Отмена по Escape ловится через `keyup` (`keydown` во время
нативного драга до страницы не доходит), поэтому итог подводится через 24 мс
после `dragend`.

Требование к потребителю: контейнер должен быть flex или grid — иначе `order`
не действует. Класс на контейнере задаёт потребитель, проверить это кит не может.
