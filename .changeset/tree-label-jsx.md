`DumbTree`: подписью узла может быть разметка (`label: JSX.Element` — например,
поле ввода при переименовании прямо в дереве), искать по такому узлу помогает
новый `searchText`. Появился проп `openDepth` — до какой глубины ветки раскрыты,
пока их не трогали руками. Ветка с выбранным узлом теперь раскрывается сама:
заход по прямой ссылке показывал свёрнутое дерево без подсветки.
