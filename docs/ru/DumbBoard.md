# DumbBoard

Доска: секции с блоками. Блоки переставляются внутри секции и переносятся между секциями, сами секции переставляются и меняют размер.

```bash
pnpm add "github:russelgal/solid-dumb-kit#path:/packages/board"
```

## Как это работает

Внутри секции блоки живут на **сетке ячеек**: размер целый — `w` колонок зоны на `h` строк, шаг строки фиксирован (`rowHeight`). Отсюда складывается вся механика:

1. **Внутри секции DOM не трогается** — место задаётся явными `grid-column-start`/`grid-row-start`, посчитанными арифметикой. Явными, а не авто-потоком: иначе браузер домысливает раскладку, и она расходится с той, по которой считается анимация.
2. **Перенос в соседнюю секцию** без перестановки DOM невозможен — блок живёт внутри своего контейнера. Это единственное место, где DOM меняется.
3. Оба случая доигрывает **FLIP**, и ему всё равно, что именно произошло, — он знает только «стартуй отсюда, приезжай в ноль».

Жест переноса — нативный drag-and-drop: зону под курсором определяет браузер, считать её самим не нужно. Ресайз — **напротив**, указательные события: перенос отвечает на вопрос «куда положить», а размер тянут покадрово, чего `dragover` не даёт.

Целые размеры дают две вещи даром. Позиции блоков — чистая арифметика, поэтому снимать их не нужно вовсе: `IntersectionObserver` наблюдает только углы зон и высоты секций, а ширину колонки и отступы даёт `ResizeObserver`. И **разметка сетки** рисуется теми же линиями, что в [DumbGrid](DumbGrid.md) — см. `showGrid`.

## Состояние

Два массива, оба у тебя:

```tsx
const [sections, setSections] = createSignal<Array<BoardSection>>([
  { id: 'sales', title: 'Продажи', cols: 3, span: 6 },
  { id: 'stock', title: 'Склад', cols: 3, span: 6, items: [] },
])
```

Блоки лежат **внутри** своих секций: `sections[i].items`. Порядок массива секций — порядок на экране, порядок `items` — порядок блоков внутри секции, размер живёт прямо на секции.

Компонент **ничего не хранит и ничего не мутирует**: на каждом шаге жеста он собирает новый массив секций и отдаёт его в `setSections`. Данные всё время совпадают с картинкой — в том числе если браузер не доставит `drop` (а он доставляет его не всегда).

## Пример

```tsx
<DumbBoard
  sections={sections()}
  setSections={setSections}
  id={(w) => w.id}
  blockSpan={(w) => w.w}            // ширина в колонках зоны; по умолчанию 1
  blockRows={(w) => w.h}            // высота в строках зоны; по умолчанию 1
  blockLimits={(w) => ({ minW: 1, maxW: 'half', minH: 1, maxH: 4 })}
  onBlockResize={(w, size) => save(w.id, size)}   // без него ручки нет
  showGrid="drag"                   // разметка сетки, пока тащат блок
  onMove={(item, toSection, toIndex) => { /* только уведомление */ }}
>
  {(w) => <article class="card">{w.title}</article>}
</DumbBoard>
```

### Размер блока — в ячейках, а не в пикселях

Ширина — `blockSpan` (колонки зоны), высота — `blockRows` (строки зоны, шаг
задаёт `rowHeight`). Высоту в пикселях задавать не надо вовсе: блок занимает
свои ячейки целиком, и мерить его доске не приходится.

Ширину можно задать долей — `'half'`, `'third'`, `'2/5'`: она разрешается по
числу колонок **зоны** и округляется вниз, чтобы N блоков по `1/N` всегда влезли
в строку.

### Пределы и ужимание: `blockLimits`

Пределы размера блока — один проп на все четыре числа:

```tsx
blockLimits={(w) => ({ minW: 1, maxW: 'half', minH: 1, maxH: 4 })}
```

`minW` работает **дважды**. Во-первых, это порог ресайза. Во-вторых — ширина, до
которой блок согласен ужаться, чтобы влезть в остаток строки вместо переезда
вниз: хочет 3 колонки, свободны 2 — встанет шириной 2; свободна 1 и `minW: 1` —
встанет шириной 1. Без `minW` блок уедет на следующую строку целым.

Ужатая ширина **нигде не хранится**: она заново выводится из раскладки, поэтому
на просторном месте блок сам разворачивается обратно до `blockSpan`. Данные при
этом не меняются — доска по-прежнему ничего не мутирует.

### Ресайз блока

Ручка появляется в правом нижнем углу блока — но **только если задан
`onBlockResize`**: размер живёт в твоих данных, и менять его без спроса доска не
станет.

```tsx
onBlockResize={(item, { w, h }) => setSizes({ ...sizes(), [item.id]: { w, h } })}
```

Пока тянут, меняется только **рамка-превью**. Сам блок меняет размер лишь после
того, как ты сохранил новый: каждая смена снапа покадрово перекладывала бы всю
зону и запускала пачку анимаций — то же решение, что в [DumbGrid](DumbGrid.md).

Жест — указательный (`pointerdown`), а не нативный DnD: размер тянут покадрово,
чего `dragover` не даёт. Поэтому ресайз работает и пальцем, в отличие от переноса.

Размеры лучше держать **отдельно от объектов блоков** (карта `id → {w,h}`): объект
блока обязан пережить переезд между секциями, а `{ ...item, w }` — уже другой
объект (см. ниже).

### Свои кнопки на блоке

Всё, что внутри блока должно нажиматься — удаление, меню, поле ввода, — помечай
`data-no-drag`, иначе нажатие уедет в перетаскивание и клика не случится.
Кнопки в шапке секции задаются пропом `sectionActions`, там метка не нужна.

Удаление доска на себя не берёт: `sections` — твой массив, выбросить из него
блок или секцию и отдать новый в `setSections` ты можешь сам.

```tsx
<button data-no-drag onClick={() => remove(item.id)}>✕</button>
```

### Одно требование к блокам

Объекты блоков должны **переживать переезд**: доска переносит тот же объект из
массива одной секции в массив другой и никогда не делает копию. Не делай её и
ты — `{ ...item }` это новый объект, `<For>` сочтёт его другим элементом и
пересоздаст узел, а пересозданный узел анимировать нечем: FLIP цепляется за
элемент, которого уже нет.

## Пропсы

| проп | тип | что делает |
| --- | --- | --- |
| `sections` | `Array<BoardSection<T>>` | секции вместе с блоками; порядок массива = порядок на экране |
| `setSections` | `(next) => void` | новая раскладка; зовётся по ходу жеста, на каждом шаге |
| `id` | `(item: T) => string` | стабильный id блока |
| `blockSpan` | `(item: T) => SpanValue` | ширина блока в колонках зоны (или доля), по умолчанию `1` |
| `blockRows` | `(item: T) => number` | высота блока в строках зоны, по умолчанию `1` |
| `blockLimits` | `(item: T) => BlockLimits` | `{ minW, maxW, minH, maxH }` в ячейках; `minW` служит и ужиманию |
| `onBlockResize` | `(item, { w, h }) => void` | блок сменил размер; **без этого пропа ручки нет** |
| `showGrid` | `boolean \| 'drag'` | разметка сетки внутри секций, по умолчанию `'drag'` |
| `labels` | `{ resizeBlock?: string }` | подпись ручки ресайза блока |
| `onMove` | `(item, toSection, toIndex) => void` | блок переехал — уведомление |
| `onSectionMove` | `(from, to) => void` | секцию перетащили за заголовок |
| `onSectionResize` | `(id, { span, rows }) => void` | секция сменила размер |
| `cols` | `number` | колонок у доски, по умолчанию `12` |
| `gap` | `number` | зазор сетки доски в px, по умолчанию `14` |
| `rowHeight` | `number` | высота ячейки зоны в px, по умолчанию `76` |
| `zoneGap` | `number` | зазор сетки внутри секции в px, по умолчанию `8` |
| `minSpan` | `number` | минимальная ширина секции в колонках, по умолчанию `3` |
| `editable` | `boolean` | правка; при `false` нет ни жестов, ни ручек, ни слушателей |
| `animate` | `boolean` | анимировать; по умолчанию да, но не при `prefers-reduced-motion` |
| `resizable` | `boolean` | разрешить ресайз секций |
| `sectionActions` | `(s) => JSX.Element` | свои кнопки в правой части шапки |

### BoardSection

| поле | что значит |
| --- | --- |
| `id` | обязателен |
| `items` | блоки секции; порядок массива = порядок на экране |
| `title` | заголовок; он же ручка переноса. Не задан — шапки нет вовсе |
| `subtitle` | приписка мельче |
| `cols` | колонок **внутри** секции, по умолчанию `3` |
| `span` | ширина секции в колонках доски, по умолчанию половина |
| `rows` | высота в строках сетки зоны; не задана — по занятым строкам плюс одна про запас |
| `accepts` | `(from: string) => boolean` — пускать ли блоки из секции `from` |

## Жесты

| действие | что делает |
| --- | --- |
| тащить блок | переставить внутри секции или перенести в соседнюю |
| тащить угол блока | изменить размер блока (нужен `onBlockResize`); работает и пальцем |
| тащить секцию за заголовок | переставить секции |
| правый край / нижний / угол секции | ширина, высота, оба сразу |
| двойной клик по шапке | во всю ширину и обратно (возвращается **та же** ширина, что была) |

## Оформление

Кит инжектит только структурные стили — сетку, позиции ручек, приглушение источника. Инжект происходит **один раз на страницу**, сколько бы досок ни отрисовалось. Всё остальное твоё: перебивай классы `.dumb-board-zone`, `.dumb-board-head`, `.dumb-board-block` из своего CSS.

## Чего он не делает

- **Не хранит раскладку.** Персист — твой (`localStorage`, сервер, что угодно); компонент только сообщает об изменениях.
- **Не поддерживает тач для переноса** — HTML5 DnD там не существует. Ресайз на указателе работает и пальцем.
- **Не расталкивает блоки каскадом.** Блок встаёт на место, соседи сдвигаются на одну позицию — предсказуемость важнее умности.
