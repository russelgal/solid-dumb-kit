# DumbDateRange

Календарь: выбрать день или период, видя занятое.

```tsx
import { DumbDateRange } from '@solid-dumb-kit/date-range'
```

## Дата — строка, а не `Date`

`YYYY-MM-DD`, и это не придирка. `Date` — момент времени в часовом поясе, и
«первое июня» у пользователя в Калининграде и на сервере в UTC оказываются
разными сутками. В бронировании это ошибка ценой в номер: заезд уезжает на день.
Внутри всё считается в UTC — тогда суток ровно столько, сколько на календаре.

## Период набирается двумя кликами

Первый — начало, второй — конец, между ними диапазон тянется за курсором. Это
привычнее протяжки: на тачскрине протяжка конфликтует с прокруткой страницы, а
два тапа работают одинаково везде.

**Занятость показывается ДО клика.** Занятые дни перечёркнуты (по диагонали, а не
цветом — видно и без него), а дни за ближайшим занятым отрезком гаснут: дотянуть
туда всё равно нельзя. Ругаться после выбора — худший вариант, человек уже успел
решить.

**Не выбралось — начинаем заново с этого дня**, а не с пустого места: почти
всегда человек промахнулся, а не передумал.

## Сетка месяца всегда 42 дня

Шесть полных недель с понедельника, включая хвосты соседних месяцев. Так
календарь не прыгает по высоте при переключении месяцев — единственное, что в
нём по-настоящему раздражает.

## Пропсы

| проп | тип | что делает |
| --- | --- | --- |
| `value`, `onChange` | `{from, to}` | выбранный период |
| `single` | `boolean` | одна дата вместо периода |
| `busy` | `() => Array<BusySpan>` | занятые отрезки |
| `marks` | `() => Record<Day, {title, class}>` | праздники и выходные |
| `months` | `number` | сколько месяцев показывать разом |
| `min`, `max` | `Day` | пределы |
| `minNights`, `maxNights` | `number` | ограничения длины |
| `dayExtra` | `(day) => JSX.Element` | цена или что угодно в углу дня |
| `onReject` | `(why) => void` | причина отказа: «занято», «минимум 3 ноч.» |

## Математика наружу

`checkRange`, `overlaps`, `reachTo`, `daysBetween`, `monthGrid` — чистые функции
без DOM. Границы суток **смыкаются**: выезд и заезд в один день не считаются
пересечением, номер освобождается утром. Этими же функциями стоит проверять
занятость на сервере.
