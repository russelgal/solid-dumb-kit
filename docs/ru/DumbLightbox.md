# DumbLightbox

Просмотрщик: картинка во весь экран, листание, зум.

```tsx
import { DumbLightbox } from '@solid-dumb-kit/lightbox'
```

Рисуется нативным `<dialog>`, то есть в **top layer**: над всем на странице, с
блокировкой фокуса и Esc от браузера. Своего `position: fixed` с `z-index: 99999`
не нужно — и он всё равно проиграл бы чужой модалке в top layer.

## Что важно внутри

**Масштаб и сдвиг — только `transform`.** Layout не трогается вовсе, поэтому зум
колесом идёт в кадре даже на большой картинке.

**Соседние грузятся заранее** — одна вперёд и одна назад, через `new Image()`.
Без этого каждое нажатие стрелки показывает пустоту, и просмотр превращается в
ожидание.

**Клик по фону закрывает, по картинке — нет.** Отличаем сравнением
`ev.target === ev.currentTarget`.

## Клавиши

| | |
| --- | --- |
| `←` `→` | листать по кругу |
| `+` `−`, колесо | масштаб |
| `0` | сбросить |
| двойной клик | увеличить и вернуть |
| `Esc`, клик по фону | закрыть |

Увеличенную картинку можно таскать.

## Пропсы

`items` (`{url, title, preview}`), `index` / `onIndexChange` — что открыто,
`actions` — свои кнопки внизу (скачать, удалить), `animate`.
