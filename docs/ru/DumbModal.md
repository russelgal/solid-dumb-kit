# DumbModal

Модальное окно на нативном `<dialog>`.

```tsx
import { DumbModal } from '@solid-dumb-kit/modal'
```

## Что браузер отдаёт даром

Всё, ради чего обычно пишут двести строк своей модалки, уже есть в `showModal()`:

- окно в **top layer** — над всем, включая чужие модалки, и его не режет
  `overflow: hidden` у предков;
- подложка `::backdrop` — отдельный `div` не нужен;
- фокус заперт внутри, Tab ходит по кругу;
- Esc закрывает;
- страница под окном не прокручивается.

## Что пришлось дописать

Ровно то, чего браузер не делает:

- **возврат фокуса** туда, откуда пришли. Запоминается ДО открытия: `showModal()`
  фокус уже уводит;
- **клик по подложке**. Нативно он не работает: у `::backdrop` своей цели нет, и
  событие приходит на сам `<dialog>` — отсюда сравнение `ev.target ===
  ev.currentTarget`;
- **защита от закрытия** (`onBeforeClose`). Esc закрывает молча, и несохранённая
  правка пропадает.

## Пропсы

| проп | тип | что делает |
| --- | --- | --- |
| `open` | `() => boolean` | открыто ли |
| `onClose` | `() => void` | закрыть |
| `title`, `footer` | `JSX.Element` | шапка и низ; не заданы — их нет |
| `onBeforeClose` | `() => boolean \| Promise<boolean>` | `false` — окно остаётся |
| `keepOnBackdrop`, `keepOnEsc` | `boolean` | не закрывать по клику мимо / по Esc |
| `width` | `string` | ширина; по умолчанию `min(560px, 92vw)` |
| `animate` | `boolean` | анимировать; при `prefers-reduced-motion` молча выключается |

## Когда НЕ модалка

Если окно рассказывает о конкретном элементе на странице — берите
[`DumbPopover`](DumbContextMenu.md). Модалка посреди шахматки закрывает ровно ту
бронь, о которой рассказывает, и после закрытия её приходится искать заново.

## Вопрос окном: `modal.confirm`

`confirm()` из браузера останавливает вкладку целиком и не даёт написать, что
именно случится. `modal.confirm` — то же по смыслу, но окном и обещанием.

```tsx
import { DumbModalHost, modal } from '@solid-dumb-kit/modal'

// ОДИН раз на приложение, рядом с корнем
<DumbModalHost />

// спрашивать можно откуда угодно: шина живёт в модуле и про разметку не знает
const ok = await modal.confirm('Удалить бронь безвозвратно?', {
  title: 'Удаление',
  yes: 'Удалить',
  no: 'Отмена',
  danger: true,
})
```

Вопросы идут **очередью** и не перебивают друг друга: `current()` говорит, что
на экране, `pending()` — сколько ждёт.

| | |
| --- | --- |
| `modal.confirm(text, opts)` | `Promise<boolean>`; закрыли не ответив — `false` |
| `modal.ask(text, actions, opts)` | несколько ответов; возвращает `value` нажатой, при закрытии — `opts.dismiss` |
| `modal.alert(text, opts)` | сообщение с одной кнопкой |
| `modal.current() / pending()` | что на экране и сколько в очереди |
| `createModalBus()` | своя шина: тесты, две независимые области |

`dismissible: false` — у вопроса нет безопасного умолчания, и закрыть его, не
ответив, нельзя.

Плашка в углу (`toast.confirm` из [`@solid-dumb-kit/toast`](DumbToast.md)) —
для случаев, когда работа продолжается; окно — когда она встала.
