# DumbSortable

**Перетаскивание для смены порядка** без зависимостей: вертикальный список **или** двумерная сетка, с автоскроллом, разной высотой строк и **без единого reflow во время драга**.

Две формы:

- **`DumbSortable`** — декларативный компонент, элемент для каждого айтема возвращаешь ты сам;
- **`createDumbSortable`** — примитив под ним (ручные ref'ы), когда нужен полный контроль (свои таблицы, существующая разметка).

```tsx
import { DumbSortable, createDumbSortable } from 'solid-dumb-kit'
```

CSS не нужен — движение это чистый инлайновый `transform`.

## Почему не дёргается

Большинство драг-либ покадрово зовут `getBoundingClientRect()` во время протяжки → forced reflow → рывки (поэтому оптимистичные перестановки в них часто приходится отключать). `DumbSortable` снимает позиции всех ячеек **один раз** на старте драга через `IntersectionObserver` (границы считаются вне главного потока, без reflow), а дальше при движении пишет только `transform` (GPU/композитор). Порядок массива коммитится один раз — на дропе.

## Компонент `DumbSortable`

```tsx
import { createSignal } from 'solid-js'
import { DumbSortable } from 'solid-dumb-kit'

const [list, setList] = createSignal([
  { id: 'a', label: 'Alpha' },
  { id: 'b', label: 'Bravo' },
  { id: 'c', label: 'Charlie' },
])

// КОНТЕЙНЕР — твой
<div class="space-y-2 overflow-auto max-h-[60vh]">
  <DumbSortable items={list()} setItems={setList} id={(x) => x.id}>
    {(item) => (
      // ЭЛЕМЕНТ — тоже твой: любой тег/классы/стили на айтем
      <div class="row">
        <button data-drag-handle>⠿</button>
        {item.label}
      </div>
    )}
  </DumbSortable>
</div>
```

Компонент рендерит `<For>` по `items`, берёт **настоящий DOM-узел**, который вернул твой `children`, и вешает драг прямо на него — без обёрток и возни с ref'ами.

### Пропсы

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `items` | `Array<T>` | — (обязательный) | Текущие айтемы в визуальном порядке. |
| `setItems` | `(next: Array<T>) => void` | — (обязательный) | Вызывается на дропе с переставленным массивом. |
| `id` | `(item: T) => string` | — (обязательный) | Стабильный id айтема. |
| `children` | `(item: T, index: () => number) => JSX.Element` | — (обязательный) | **Должен вернуть один корневой DOM-элемент** — к нему привязывается драг. |
| `axis` | `'y' \| 'grid'` | `'y'` | `y` — вертикальный список, `grid` — двумерная сетка (дельта по X и Y, диагональный переход через границу ряда). |
| `disabled` | `() => boolean` | — | Отключить перетаскивание (например, пока включена сортировка по колонке). |
| `animate` | `boolean` | см. ниже | Анимировать расступание соседей и приземление. |
| `pressDelay` | `number` | `350` | Тач: сколько мс держать до старта драга; движение раньше = скролл. `0` — старт сразу. |
| `mousePressDelay` | `number` | `0` | Мышь: долгое нажатие (мс) до старта. Приоритетнее `mouseThreshold`. |
| `mouseThreshold` | `number` | `0` | Мышь: сколько px пройти до старта драга. `0` — старт сразу. |

### Ручка для перетаскивания

Повесь `data-drag-handle` на потомка — тянуть можно будет только за него. Не вешаешь — перетаскивается **весь элемент**.

```tsx
{(item) => (
  <div class="row">
    <button data-drag-handle>⠿</button>   {/* тянем за это */}
    <span>{item.label}</span>             {/* клики здесь не начинают драг */}
  </div>
)}
```

## Примитив `createDumbSortable`

Нужен, когда элемент нельзя вернуть из одной render-функции — например, headless-таблица, где строки и ручки разводятся по разным местам. Возвращает ref'ы, которые ты вешаешь сам.

```tsx
import { For } from 'solid-js'
import { createDumbSortable } from 'solid-dumb-kit'

const s = createDumbSortable({
  order: () => rows().map(r => r.id),
  onEnd: (from, to) => {
    const next = rows().slice()
    next.splice(to, 0, next.splice(from, 1)[0])
    setRows(next)
  },
})

<For each={rows()}>
  {(r) => (
    <div ref={s.bind(r.id)} class="row">
      <button ref={el => {}} data-drag-handle>⠿</button>
      {r.label}
    </div>
  )}
</For>
```

### Опции (`DumbSortableOptions`)

| Опция | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `order` | `() => string[]` | — (обязательная) | Текущий визуальный порядок id (должен совпадать с порядком данных). |
| `onEnd` | `(fromIndex, toIndex) => void` | — (обязательная) | Зафиксировать перестановку (индексы внутри `order()`). |
| `axis` | `'y' \| 'grid'` | `'y'` | Список или сетка. |
| `disabled` | `() => boolean` | — | Блокирует драг, когда `true`. |
| `pressDelay` | `number` | `350` | Тач: долгое нажатие, мс. |
| `mousePressDelay` | `number` | `0` | Мышь: долгое нажатие, мс (приоритетнее `mouseThreshold`). |
| `mouseThreshold` | `number` | `0` | Мышь: дистанция до старта, px. |

### Хендл (`DumbSortableHandle`)

| Ref | Сигнатура | Когда использовать |
| --- | --- | --- |
| `bind(id)` | `(el: HTMLElement) => void` | **Всё в одном**: регистрирует ячейку *и* вешает старт драга. Ищет потомка `[data-drag-handle]` (делегированно); если его нет — ручкой становится весь элемент. Предпочтительный вариант. |
| `row(id)` | `(el: HTMLElement) => void` | Низкий уровень: только зарегистрировать элемент ячейки. |
| `handle(id)` | `(el: HTMLElement) => void` | Низкий уровень: повесить старт драга на отдельный элемент-ручку. Использовать в паре с `row`. |

Используй **либо** один `bind`, **либо** `row` + `handle` вместе (когда ручка не является DOM-потомком ячейки).

## Как выключить анимацию

`animate={false}` убирает и переход соседей, и приземление — элементы просто встают на места.

Если проп не задан, анимация **включена, но кит уважает `prefers-reduced-motion: reduce`** и сам выключается для тех, кто попросил у системы меньше движения. Явное `animate={true}` перебивает и это — на редкий случай, когда ты точно знаешь, что делаешь.

Тот же проп есть у `createDumbSortable`, `createSortableGroup`, `DumbTree` и `DumbTable`.

## Детали поведения

- **Разная высота строк** (`axis: 'y'`) — соседи сдвигаются на свои реально замеренные высоты, а не на усреднённый шаг.
- **Сетка** (`axis: 'grid'`) — айтемы перетекают по дельте X/Y и прыгают по диагонали при переходе через границу ряда (предполагается одинаковый размер ячеек).
- **Автоскролл** — драг у края контейнера/вьюпорта прокручивает его; скорость нарастает по мере того, как ты уходишь за край. Работает с ближайшим скроллящимся предком, иначе — с окном.
- **Отклик на подъём** — перетаскиваемый элемент получает лёгкое увеличение и тень; на тач-устройствах в момент срабатывания долгого нажатия идёт короткая вибрация `vibrate(8)`.
- **Приземление** — на дропе строка доезжает до нового места анимацией, а не телепортируется; целевая позиция известна из стартового снимка, поэтому мерить ничего не нужно.
- **Координаты** считаются в системе контента контейнера (минус top/left, плюс скролл), поэтому хиттест и сдвиги не ломаются от прокрутки посреди драга.
