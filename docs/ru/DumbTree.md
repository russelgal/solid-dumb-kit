# DumbTree

Дерево: вложенные узлы, ленивая подгрузка ветки, поиск, выбор.

```tsx
import { DumbTree, type TreeNode } from '@solid-dumb-kit/tree'
```

Узлы задаются **вложенно** (`children`), а не плоским списком с `parent`: из
хранилища дерево так и приходит, а разворачивать его в плоский массив только
ради компонента — работа на каждом ответе.

## Как это работает

**Ветку можно не грузить заранее.** `loadChildren(id)` зовётся в момент
раскрытия, поэтому дерево на десять тысяч узлов открывается мгновенно и тянет
только то, куда полезли. Есть и то и другое — `children` побеждает.

**Полосы — один градиент на всё дерево**, с шагом в строку (`1lh`), а не класс
на каждую вторую. Иначе при раскрытии вложенной ветки счёт начинается заново
внутри каждого уровня и сбивается с общего ритма. `background-attachment: local`
— чтобы полосы ехали вместе с прокруткой.

**Строка ровно в `1lh`.** На этом держатся полосы, и отсюда же размер дерева
одним пропом `size`: меняешь кегль — строки, полосы и отступы едут следом сами.

**Стрелка одна на оба состояния.** Раскрытая — тот же значок, повёрнутый на 90°:
он не прыгает между двумя разными глифами и анимируется даром.

Своих значков и цветов компонент **не несёт**: значки приходят классами
(`icons`), цвета — CSS-переменными с контрастными фолбэками. Tailwind и daisyUI
не требуются, но и не мешают.

## Значки — это классы

```tsx
const icons = {
  twist: 'icon-[solar--alt-arrow-right-outline]',
  folder: 'icon-[solar--folder-bold] text-sky-600',
  folderOpen: 'icon-[solar--folder-open-bold] text-sky-600',
  leaf: 'icon-[solar--document-text-outline]',
}

<DumbTree roots={nodes()} icons={icons} selected={picked} onSelect={(n) => go(n.id)} />
```

Строки живут в *твоих* исходниках, значит их компилирует *твой*
Tailwind/iconify — сканировать `node_modules` не нужно никому. Не задал вовсе:
стрелка рисуется как `▸`/`▾`, строки идут без значков.

## Ветка по требованию

```tsx
<DumbTree
  loadChildren={(parentId) =>
    fetch(`/api/tree?parent=${parentId}`).then((r) => r.json())
  }
  refreshKey={() => version()}   // сменился — уже загруженные ветки перечитаются
  icons={icons}
/>
```

`loadChildren('')` тянет корни. Ветка тянется при первом раскрытии: запрос
уходит ровно тогда, когда в неё полезли, потому что ветка вообще рендерится
только раскрытой.

## Пропсы

| проп | тип | что делает |
| --- | --- | --- |
| `roots` | `Array<TreeNode>` | дерево целиком; не задано — тянем через `loadChildren('')` |
| `loadChildren` | `(parentId) => Promise<Array<TreeNode>>` | ветка по требованию |
| `selected` | `() => string \| null` | выбранный узел |
| `onSelect` | `(node) => void` | клик по строке |
| `onContextMenu` | `(ev, node) => void` | правый клик по строке |
| `storageKey` | `string` | ключ `localStorage` для раскрытых веток; не задан — не помним |
| `refreshKey` | `() => number \| string` | сменился — загруженные ветки перечитываются |
| `query` | `() => string` | фильтр по названию: совпавшие и дорога к ним |
| `match` | `(node, query) => boolean` | свой матчер; по умолчанию подстрока без учёта регистра |
| `icons` | `DumbTreeIcons` | `twist` · `folder` · `folderOpen` · `leaf`, всё — классы |
| `size` | `string` | размер дерева одним кеглем |
| `stripes` | `boolean` | полосы через строку; по умолчанию есть |
| `renderAction` | `(node) => JSX.Element` | свой контент справа в строке |
| `getDragData` | `(node) => {type, id, label} \| null` | делает строку перетаскиваемой |

### TreeNode

| поле | смысл |
| --- | --- |
| `id` | обязателен, уникален |
| `label` | что написано в строке |
| `isFolder` | ветка ли это; узел с `children` считается веткой и без флага |
| `children` | вложенные узлы |
| `badge` | мелким справа: счётчик, размер, статус |
| `icon` | свой класс значка этой строки |
| `href` | строка становится ссылкой; навигация твоя |
| `class` | доп. класс на строку |

## Цвета

| переменная | что красит |
| --- | --- |
| `--dumb-tree-size` | кегль (или проп `size`) |
| `--dumb-tree-zebra` | полосу |
| `--dumb-tree-hover` | строку под курсором |
| `--dumb-tree-sel` · `--dumb-tree-accent` | выбранную строку |
| `--dumb-tree-dim` | бейдж и стрелку |

Дефолты намеренно контрастные: подпись читают, по стрелке попадают — серому по
серому тут не место.

## Что ушло при переписывании

Прежний `DumbTree` принимал **плоский** массив `nodes` с `parent`, рисовал своё
поле поиска и переключатель сортировки индекс/название, умел работать плоским
списком с перетаскиванием и был размечен классами daisyUI. Всего этого больше
нет: поле поиска рисует потребитель (за сам фильтр отвечает проп `query`),
плоский сортируемый список — это [`DumbSortable`](DumbSortable.md), а вид
больше не привязан к daisyUI.
