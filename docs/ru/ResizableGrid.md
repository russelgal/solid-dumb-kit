# ResizableGrid

Панельная раскладка с колонками, которые **тянутся мышью** (и опциональным вторым рядом), с **сохранением размеров в `localStorage`**. Размеры хранятся в `fr`, поэтому при изменении размера контейнера пропорции сохраняются.

```tsx
import { ResizableGrid } from 'solid-dumb-kit'
```

Импортировать CSS не нужно — стили ручек инжектятся один раз в рантайме.

## Пример

```tsx
import { ResizableGrid } from 'solid-dumb-kit'

<div style={{ height: '100vh' }}>
  <ResizableGrid
    storageKey="app:layout"
    cols={[
      { id: 'tree',   min: 180, initial: 1, content: () => <Tree /> },
      { id: 'main',   min: 320, initial: 3, content: () => <Main /> },
      { id: 'aside',  min: 200, initial: 1, content: () => <Aside /> },
    ]}
    rows={[
      { id: 'log',    min: 120, initial: 1, content: () => <Log /> },
    ]}
    rowInitial={2}   // верхнему ряду 2fr высоты
    row2Initial={1}  // нижнему — 1fr
    rowMin={120}
  />
</div>
```

> Грид растягивается на родителя (`h-full w-full`). Высоту задавай **родителю**.

## Пропсы

| Проп | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `cols` | `GridPanel[]` | — (обязательный) | Колонки первого ряда (рекомендуется 2–3). |
| `storageKey` | `string` | — (обязательный) | Ключ `localStorage`, под которым сохраняются размеры. |
| `rows` | `GridPanel[]` | — | Необязательный второй ряд панелей (1–3). Включает горизонтальный разделитель. |
| `rowInitial` | `number` | `1` | Высота первого ряда в `fr`. |
| `row2Initial` | `number` | `1` | Высота второго ряда в `fr`. |
| `rowMin` | `number` | `100` | Минимальная высота ряда, px. |
| `class` | `string` | — | Доп. класс на контейнер грида. |

### `GridPanel`

| Поле | Тип | По умолчанию | Описание |
| --- | --- | --- | --- |
| `id` | `string` | — (обязательное) | Уникальный id панели. |
| `content` | `() => JSX.Element` | — (обязательное) | Render-функция тела панели. |
| `min` | `number` | `100` | Минимальный размер в px (ширина — и для колонок, и для колонок второго ряда). |
| `initial` | `number` | `1` | Начальный размер в `fr`. |

> `content` — это **функция** (`() => <Panel/>`), а не JSX-значение. Компонент принципиально никогда не читает JSX панелей в обработчиках ресайза, поэтому протяжка не пересоздаёт твои панели.

## Как это работает

- Колонки/ряды раскладываются CSS Grid'ом: `fr`-треки, между ними ручка 6px.
- Протяжка ручки перераспределяет `fr` между двумя соседними треками, с клампом — ни один не проваливается ниже своего `min` (px пересчитываются в `fr` относительно текущего размера контейнера).
- Тело каждой панели — `overflow: auto` с `min-width/height: 0`, поэтому длинный контент скроллится, а не разрывает трек.

## Персистентность

Размеры хранятся как `{ cols, rows?, rowSplit? }` под ключом `storageKey`. При загрузке они валидируются через `valibot`; если данные битые **или число колонок больше не совпадает** с текущим `cols` — берутся значения из `initial`. Чтобы сбросить старые сохранённые раскладки, поменяй `storageKey` (или длину `cols`).

## Ограничения

- Ресайз работает **только мышью** (`mousedown`/`mousemove`), тач-ручек нет.
- Рассчитан на 2–3 колонки и опциональный второй ряд — это не произвольное дерево вложенных сплитов.
- Подсветка ручки при наведении/протяжке — `currentColor` с низкой прозрачностью, поэтому вписывается в твою тему.
