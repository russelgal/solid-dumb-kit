# @solid-dumb-kit/date-range

Выбор даты и периода: календарь, протяжка по дням, занятость

Часть [solid-dumb-kit](https://github.com/russelgal/solid-dumb-kit) — набора
компонентов для SolidJS, у которых за жест не бывает ни одного forced layout.

```bash
pnpm add @solid-dumb-kit/date-range
```

Peer-зависимости: `solid-js` и `@solidjs/web` — вторая линия Solid (`>=2.0.0-beta.30`). Рантайм-зависимостей нет.
