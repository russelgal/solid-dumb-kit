# @solid-dumb-kit/grid-dnd

Та же сетка на нативном HTML5 drag-and-drop

Часть [solid-dumb-kit](https://github.com/russelgal/solid-dumb-kit) — набора
компонентов для SolidJS, у которых за жест не бывает ни одного forced layout.

```bash
pnpm add @solid-dumb-kit/grid-dnd
```

Пальцем не работает: нативного drag-and-drop на тачскрине не существует. Нужен
жест пальцем — бери указательную пару (`@solid-dumb-kit/grid`,
`@solid-dumb-kit/sortable`).

Peer-зависимость: `solid-js@^1.8.0`.
