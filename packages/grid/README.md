# @solid-dumb-kit/grid

Дашборд-сетка: режимы flow/dense/free, снап-ресайз, вложенность

Часть [solid-dumb-kit](https://github.com/russelgal/solid-dumb-kit) — набора
компонентов для SolidJS, у которых за жест не бывает ни одного forced layout.

```bash
pnpm add @solid-dumb-kit/grid
```

Peer-зависимость: `solid-js@^1.8.0`. Тянет за собой: `@solid-primitives/storage`, `valibot`.
