# @solid-dumb-kit/locator

## 0.1.0

### Minor Changes

- 305126b: Новый пакет: **alt-клик по элементу открывает его разметку в редакторе**.
  
  Половина для сборщика — плагин Vite `locator()` (`@solid-dumb-kit/locator/vite`):
  ставит каждому элементу атрибут `data-loc="файл:строка:колонка"`. Браузерная —
  `createLocator()`: ловит alt-клик, берёт место у ближайшего предка и зовёт
  ШТАТНЫЙ эндпоинт дев-сервера Vite `/__open-in-editor`, который сам и выбирает
  редактор (по запущенному процессу либо по `LAUNCH_EDITOR`).
  
  Своего эндпоинта пакет не заводит и в сборку не попадает вовсе (`apply: 'serve'`).
  Разметка строковая: парсер даёт позиции тегов, атрибут вставляется в ту же
  строку, код не перегенерируется — номера строк и карты кода остаются верными
  (64 файла, 852 атрибута, 169 мс на весь `src` проверенного проекта).
  
  Написано потому, что готового под Solid 2 нет: локатор `solid-devtools` держится
  на внутренностях Solid 1.9 (peer `solid-js@^1.9.0`, `vite ≤7`), инспекторы
  React/Vue/Svelte — про свой JSX, а `@builder.io/vite-plugin-jsx-loc` заброшен на
  `vite ^4 || ^5`.
  
  Сборка: `configs/tsup.ts` собирает вторым входом `src/vite.ts`, если файл есть, —
  тем же правилом «есть файл, значит собираем», по которому уже выбирается
  расширение основного входа. У остальных пакетов сборка не изменилась (проверено
  побайтно по `dist`).
