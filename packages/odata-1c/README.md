# @solid-dumb-kit/odata-1c

Клиент стандартного интерфейса OData 1С — без Solid и без зависимостей

Часть [solid-dumb-kit](https://github.com/russelgal/solid-dumb-kit) — набора
компонентов для SolidJS, у которых за жест не бывает ни одного forced layout.

```bash
pnpm add @solid-dumb-kit/odata-1c
```

Solid не нужен: пакет без фреймворка.
