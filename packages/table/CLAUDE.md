# packages/table — DumbTable

Железные правила репы (никакого reflow, daisyUI, контраст, импорты под Solid 2)
лежат в корневом `CLAUDE.md` и действуют здесь тоже.

## Сортировка — своя, без TanStack
`@tanstack/solid-table` выкинут: восьмая версия тянет `solid-js/store`, которого
во второй линии Solid нет вовсе, а в девятой API переписан целиком — и всё это
ради сортировки по колонке. Теперь у пакета **ноль рантайм-зависимостей**, вся
сортировка — `compare` + стабильный `sort` в `DumbTable.tsx`.

- Значение для сортировки берётся из `row[key]`; нужно другое — проп колонки `value: (row) => unknown` (не `accessorFn`, его больше нет). Ничего объявлять не обязательно: колонка сортируется, как только у неё `sortable`.
- Первый клик по заголовку: текстовые колонки начинают с `asc`, **числовые с `desc`** — определяется по типу первого непустого значения. Перебивается пропом `sortDescFirst`. Тесты на сортировку пиши с оглядкой на это.
- Сортировка **стабильная** (сравнение через индекс), пустые (`null`/`undefined`/`''`) всегда в конце — в обе стороны. Строки сравниваются `localeCompare('ru', { numeric: true })`, поэтому «файл2» идёт раньше «файл10».
- При `onReorder` слева добавляется колонка с ручкой, поэтому индексы `<th>` сдвигаются на единицу — легко ошибиться в тестах.
- Драг строк выключается, пока активна сортировка: `from → to` описывают отображаемый порядок, который при сортировке не совпадает с порядком данных. Та же логика, что у `DumbTree` при активном поиске.
- Таблица **не пагинирует** — строки режет потребитель, `DumbPagination` только рисует пагинатор. При драге на странице не забывать про смещение `(page-1) * pageSize`.
