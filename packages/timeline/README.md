# @solid-dumb-kit/timeline

Шахматка: ресурсы × дни, полосы с драгом и ресайзом по сетке

Часть [solid-dumb-kit](https://github.com/russelgal/solid-dumb-kit) — набора
компонентов для SolidJS, у которых за жест не бывает ни одного forced layout.

```bash
pnpm add @solid-dumb-kit/timeline
```

Peer-зависимость: `solid-js@^1.8.0`. Тянет за собой: `temporal-polyfill`.
