solid-dumb-kit — MCP-сервер

Знания о ките для агента: пакеты, пропсы компонентов, примеры, документация и правила репозитория. Без клона и без установки — одним адресом. 

claude mcp add --transport http solid-dumb-kit https://solid-dumb-kit.vercel.app/mcp

Проверить, что сервер жив и чем набит: /mcp — отдаёт версию, время сборки снимка и число файлов в нём.

Инструменты

ИнструментЧто отдаёт
list_packagesвсе пакеты: имя, версия, за что отвечает
package_apiбарр-файл пакета — в ките у каждого экспорта есть комментарий
component_propsтип пропсов компонента вместе с JSDoc над полями
exampleисходник рабочего примера; их держит в актуальном виде тест
docsстраница документации, русская или английская
rulesжелезные правила: никакого reflow, импорты под Solid 2, контраст
searchпоиск по исходникам, примерам и докам

Исходники: github.com/russelgal/solid-dumb-kit · витрина компонентов: russelgal.github.io/solid-dumb-kit

Данные — снимок репозитория, собранный на деплое. Он пересобирается на каждый пуш в main, так что ответы догоняют репозиторий сами. Нужны невыпущенные правки — запускай сервер локально по stdio, он читает рабочую копию.
